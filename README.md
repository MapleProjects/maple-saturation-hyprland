# Maple Saturation Control — Hyprland

Screen color saturation control for Hyprland via GLSL shaders.

## Features
- Real-time saturation adjustment via GUI slider (PyQt6)
- GLSL ES 320 shader (no external dependencies)
- Dark Catppuccin Mocha theme
- Settings persistence

## Install (AUR)
```bash
paru -S maple-saturation-hyprland-git
```

## Usage
```bash
maple-saturation
```

## Dependencies
- Hyprland
- python-pyqt6
- hyprctl
